# Puffle 3 Emulator: PS3 branding update

The user-supplied logo is preserved as `assets/puffle3_logo_source.jpg` (the
upload had a .png filename but contains JPEG data). Nothing was generated by AI.

- `assets/ICON0.PNG`: 320 x 176, XMB application's icon.
- `assets/PIC1.PNG`: 1920 x 1080, XMB application's background.
- `Makefile`: copies both images into the PS3 PKG staging directory and sets
  the XMB title to **Puffle 3 Emulator**.
- `assets/sfo.xml`: matching TITLE and existing app identifier.
- `src/ps3_main.c`: titles of the in-app menus say **Puffle 3**.

The executable still uses Ruffle as the Flash engine. Its `/dev_hdd0/ruffle/`
storage paths, install title ID `RFLP00001`, and PS3 content ID are **unchanged**,
so the branding does not deliberately break existing games, saves or profiles.

To rebuild: provision the PS3 SDK and Ruffle dependency as described in
`README.md`, then `make package`. The `package` target now picks up this logo.

Note: this is a source/assets update only. The original 01.04 PKG in the user
upload has not been rebuilt, re-signed, or repackaged.
