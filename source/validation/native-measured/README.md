These are measurement utilities, not console release code. Run from a workspace containing tooling/squashfs-root (RPCS3 0.0.43-20551), tooling/desktop (extracted Xvfb/xdotool/Mesa/LLVM20 dependencies), emulator/config/rpcs3 (firmware installed separately), and evidence/. Pillow is required for snapshots. Native config is archived with the evidence. No firmware or game SWFs are bundled.

The runner boots the installed EBOOT and uses GAME_INDEX=0/1/2 for Bullet Bill/Mario/Right Mix. Each session needs a free display number and a distinct stop filename. Control requests go in evidence/native-command.json: {"key":"x","seconds":0.3}, {"shot":"evidence/name.png"}, or {"click":[551,479]}. Touch the exact stop filename in the runner to stop. The runner's historical stop message says “8 GiB RSS guard” for both explicit stop and RSS guard; manual phase stops were intentional, not memory failures. Use the app/TTY/trap logs for actual failures.
